# Worked example — warung-pos

Sample of what devpilot generates. This is the (abridged) output of running
`/devpilot init` for a fictional small-restaurant POS web app, answering the
interview with: web app, English docs, Laravel + Vue + PostgreSQL, divisions
Frontend/Backend/UI-UX/QA.

Shown here: `config.md`, `features.md`, `design.md`, `phases.md`
(mid-execution, so you can see task-level progress tracking) and the three
generated formal docs — `prd.md`, `srs.md`, `timeline-gantt.md`. A real run
also produces `requirements.md`, `tech-stack.md`, `architecture.md`,
`database.md`, `api-contract.md`, and `backlog.md`.
